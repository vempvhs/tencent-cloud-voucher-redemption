## 腾讯云代金券有哪几种获取方式？

官方渠道就三种：官网活动页、微信卡券、线下纸质兑换券。活动页发的是电子代金券，后两种发的是“兑换券”，性质不太一样。

**官网活动页**是最常用的入口。腾讯云在大促、年底大酬宾这类节点会放出电子代金券，不同活动的券在面额、适用产品、使用门槛上都不一样，具体以当次活动规则为准。活动发放的券一般直接进入账户，状态显示“待使用”。

**线下纸质兑换券**来自线下活动或合作渠道，同样要走兑换流程。

代金券和兑换券别搞混：兑换券只是一张“提货单”，兑换成功后才变成账户里能抵扣费用的电子代金券。

## 领到的券在哪里查看？

费用中心「代金券」页面能看到账户下所有券。状态分待使用、已使用、已过期三种；如果订单已确认但还没支付，券会显示为已冻结。

- **待使用**：未使用且未过期，可以抵扣费用。开通按量计费产品时的冻结费用除外。
- **已冻结**：订单已经确认、还没支付，这张券被暂时占住。
- **已使用**：余额已经用完。
- **已过期**：超过有效期，不能再用。有效期也不能延长。

## 付款时怎么用？预付费和后付费不一样

预付费在付款页面手动勾选，后付费由系统在结算时自动抵扣，两种场景的操作方式完全不同。

**预付费（包年包月）**：新购、手动续费、变更配置时，付款页面会把符合条件的券列出来，勾选就行。一次支付只能用一张券。多笔订单可以先在订单管理里合并付款，合并后共用一张券。设置了自动续费的资源，系统自动续费时会优先用适用的代金券抵扣，再扣账户余额。

**后付费（按量计费）**：按小时、按天或按月结算时，系统自动选用可用的券，不用手动操作。注意开通后付费产品时的冻结费用不能用券抵扣。抵扣了多少，可以在账单详情里看到代金券支付金额。

| 场景 | 用券方式 | 单次可用券数 | 需要留意 |

| 预付费（新购 / 续费 / 升配） | 付款页面手动勾选 | 1 张 | 可合并付款共用一券；退款时券不退 |
| 后付费（按量计费） | 系统结算时自动抵扣 | 1 张 | 开通时的冻结费用不可用券 |

## 付款页看不到券？对照这几条限制

最常见的原因是订单和券的限制条件对不上：适用产品不符、没到金额门槛、购买时长超出限购范围，任意一条都会让券从付款页“消失”。

完整排查清单：

| 限制项 | 具体规则 |
| --- | --- |
| 适用产品 | 指定产品券只能买对应产品；通用券有排除清单，清单外的产品都能用 |
| 金额门槛 | 按单次支付计算，订单里适用产品的总金额达到门槛才能用 |
| 限购时长 | 券限定 0–3 个月，订单购买时长就必须在 3 个月以内 |
| 付费类型 | 预付费券不抵后付费账单，后付费券也不抵包年包月订单 |
| 有效期与状态 | 已过期、已用完、已冻结的券都不能用于新订单 |
| 账户与订单 | 欠费不能抵扣；部分促销订单、代付订单用券规则不同 |

操作权限也查一下：只有账户创建者和拥有财务权限的协作者、子用户能使用和管理代金券，权限不够的账号登录进去看不到相关入口。

还有一条容易忽略：代金券不能用来抵扣已经欠下的费用，得先把欠费结清。

## 一次支付只能用一张，系统按什么顺序挑券？

系统会在所有满足条件的待使用券里，按过期时间先后、可抵扣金额大小、余额大小排序，优先用先过期且能覆盖订单全额的券。

排序规则具体是：

1. 先看过期时间，越早过期的越优先。
2. 同样条件下，优先用可抵扣金额大的券。
3. 可抵扣金额相同时，优先用余额小的券。

放到实际场景里：如果一张快过期的小额券刚好能抵完订单，系统会先用它；如果所有券都抵不完，就在最早过期的券里挑抵扣金额最大的那张。

每张券还有一个自动用券开关，默认打开。自动续费、后付费结算这类场景下，系统会自动把券用掉。如果你打算把某张券留给后面的订单，可以在代金券列表里单独关掉它的自动用券，用的时候再手动开回来。券消耗完或过期后，开关状态不会变。

## 几个容易吃亏的细节

代金券有几条不太起眼、但碰上就是实际损失的规则，主要集中在退款、转赠和扣款方式上。

- **退款不退券**：预付费产品退款时，购买时使用的代金券不退还。
- **单次券用完即止**：单次使用的券用一次后状态就变“已使用”，哪怕还有余额也不能再用；多次使用的券才能一直用到余额耗尽或过期。
- **不可提现、转赠、开票**：代金券只能用于抵扣费用，这三点没有例外。
- **分摊扣款**：一张券同时抵多个订单时，系统按各订单金额比例分摊。比如两个订单分别 100 元和 200 元，券余额只有 90 元，则分别抵扣 30 元和 60 元，剩余部分用账户余额补。

## 常见问题

**代金券可以叠加使用吗？**
不能。一次支付只能用一张代金券，多张券不能同时抵扣同一笔订单。

**券快过期了，有效期能延长吗？**
不能。代金券的有效期不可延长，到期即作废。

**账户欠费了还能用券吗？**
不能。代金券不能抵扣欠费费用，需要先结清欠费才能正常用券消费。

**微信卡券的兑换码是多少位？**
8 位字母。兑换时注意不要带多余空格，输入后确认弹出兑换券信息即可。
